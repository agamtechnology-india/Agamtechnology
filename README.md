# Agam Technology Website

Official website for **Agam Technology**.

## 🚀 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/agamtechnology-india/Agamtechnology.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
